# Requirements

## 1. Purpose

`plotcore` provides fast, interactive visualization of GNSS positioning solution data for inspecting and comparing trajectories and solution quality.

The project consists of multiple native applications that share file parsing, normalized data, coordinate processing, reference comparison, statistics, diagnostics, and plotting components.

The first implementation target is `plotcore light`, which provides a fixed and compact interface. `plotcore full` is implemented after light as an extension that provides a workspace-style multi-area interface while reusing the same shared components.

The project does not aim to perform positioning computations or reproduce the complete RTKPLOT feature set. It focuses on the plotting functions required for efficient inspection of recorded positioning results.

## 2. 対象範囲

### 2.1 製品構成と実装順

`plotcore`は、共通のデータ処理、解析およびプロットcomponentを使用する複数のnative applicationで構成する。

- `plotcore light`: 固定的で簡潔なwindow layoutを持つapplication
- `plotcore full`: 任意個のfloating plot areaを扱うworkspace型application

現在の実装対象は`plotcore light`とする。`plotcore full`は、lightで共通componentの機能、性能および境界を検証した後に、同じcomponentを再利用する拡張として実装する。

lightとfullは同一application内の表示modeではなく、別のapplication targetとして定義する。

### 2.2 plotcore lightの初期実装対象

初期実装では、以下の機能を対象とする。

- RTKLIBまたはMRTKLIB形式に準じる測位解ファイルの読み込み
- NMEA形式の位置ログの読み込み
- 複数ファイルの一括読み込みおよび同時表示
- 共通の局所East/North座標系による水平軌跡の表示
- East、Northおよび鉛直位置成分の時系列表示
- 時系列表示の鉛直位置成分として、局所座標系のUpまたは楕円体高を選択する機能
- スロット1を基準とした複数ファイルの相対水平位置表示
- 相対位置の成分別時系列表示
- 相対距離の時系列表示
- 通常表示と基準相対表示の切り替え
- 水平軌跡と時系列の単独表示および同時表示
- 測位解品質による表示の区別
- ファイル単位および測位解品質単位の表示・非表示の切り替え
- マウス操作によるパンおよびズーム
- 各軸の表示範囲、描画領域長および水平軌跡の表示縮尺の数値指定
- 表示中のデータに対する表示範囲の自動調整
- 軸、単位、目盛りおよびグリッドの表示

対応する入力形式およびデータの解釈規則の詳細は、`data-specification.md`で定義する。

### 2.3 plotcore lightの初期実装対象外

初期実装では、以下の機能を対象外とする。

- `plotcore full`固有の任意個のfloating plot areaおよびそのinstance管理
- GNSS測位計算
- 受信機からのリアルタイム入力
- シリアルポートからの入力
- TCP、UDPまたはNTRIPによるストリーム入力
- RINEX観測ファイルまたは航法ファイルの処理
- RTCMのデコード
- 衛星配置図
- 衛星観測値および追尾状態のプロット
- 残差、アンビギュイティまたはDOPのプロット
- 地図タイルまたは地理的背景地図の表示
- 三次元表示
- 軌跡データの編集
- 入力ファイルの変更
- RTKPLOTとの完全な機能互換性
- RTKPLOTとの設定互換性
- ブラウザ、ElectronまたはWebViewを利用した実行（恒久的に対象外）

### 2.4 plotcore fullの対象

`plotcore full`では、共通機能に加えて以下を対象とする。

- File/Slots areaの表示および非表示
- Normal 2D、Normal Time Series、Relative 2DおよびRelative Time Seriesの4種類のplot area
- 各種類のplot areaを任意個生成する機能
- 各plot areaを独立したfloating areaとして配置する機能
- plot areaごとの表示、非表示、再表示および削除
- plot areaごとの軸範囲、描画領域長、表示縮尺、zoom/pan状態および表示成分
- 全plot areaで共有するファイル、スロット、品質filter、共通時刻範囲、ENU基準およびrelative data

`plotcore full`の実装は、`plotcore light`の初期実装完了後に行う。

### 2.5 将来検討する機能

以下の機能は、初期実装の表示機能および性能を検証した後に検討する。

- 三次元軌跡の表示
- 衛星数、衛星追尾状態、DOPおよびsky plotを含む観測状態の表示
- プロット画像の保存
- マウスオーバーしたsampleの時刻、座標および関連情報の表示
- 同一sampleを時系列、水平軌跡および観測状態等の複数のプロット上で連動して強調表示する機能
- プロット配置および表示設定の組合せをレイアウトセットとして保存する機能
- 地理的背景地図上での軌跡表示
- 緯度、経度および高さによる位置表示
- ドラッグ・アンド・ドロップによるファイル読み込み
- 入力ファイル変更時の自動再読み込み
- 処理済みデータの出力
- プロジェクトまたはワークスペースの保存
- リアルタイムデータ入力
- RTKPLOTが提供する追加のプロット種別
- Windows向け配布パッケージ

本節に将来検討項目として記載した機能は、`plotcore light`の初期実装要件には含めない。

## 3. 利用ワークフロー

### 3.1 ファイルを開く

利用者は、1個または複数の対応ファイルを選択して読み込む。

プログラムはファイルごとに読み込みの成否を判定する。読み込みに成功したファイルは表示対象へ追加し、読み込みに失敗したファイルは追加しない。

複数ファイルの一部で読み込みに失敗した場合も、読み込みに成功したファイルの処理および表示を継続する。失敗したファイルについては、対象ファイルおよび失敗理由を利用者へ通知する。

表示対象となるファイルが存在しない状態から最初のファイルを読み込んだ場合は、読み込んだデータ全体が表示されるように表示範囲を自動調整する。

### 3.2 ファイルを追加する

既にファイルを表示している状態で、別のファイルを追加できる。

追加前から存在するファイルの表示状態および現在の表示範囲は維持する。新たに読み込んだファイルは、既定で表示状態として追加する。追加時には表示範囲を自動変更しない。

利用者は、明示的に全表示対象へ表示範囲を合わせる操作を実行できる。

### 3.3 複数ファイルを比較する

読み込み済みファイルは、`1`から`n`までの連続したスロットへ配置する。利用者はスロット順を入れ替えられる。

通常表示では、複数ファイルの軌跡および時系列を同時に表示できる。

基準相対表示では、スロット1を基準ファイルとし、スロット2以降の各ファイルについて相対水平位置、相対位置の成分別時系列および距離時系列を表示する。

各ファイルは個別に表示または非表示へ切り替えられる。測位解品質による表示条件は、表示中の全ファイルに共通して適用する。

### 3.4 plotcore lightの表示モードを切り替える

`plotcore light`の利用者は、通常表示および基準相対表示について、それぞれ水平軌跡、時系列または両方の表示をタブで選択できる。

両方表示では、水平軌跡と時系列を左右に配置する。中央の境界線をドラッグして左右の表示幅を変更でき、境界線をダブルクリックすると中央へ戻る。

### 3.5 鉛直位置成分を切り替える

利用者は、位置時系列の鉛直成分として、局所座標系のUpまたは楕円体高を選択できる。

鉛直成分の選択は、表示中の全ファイルに共通して適用する。同一の時系列表示内で、Upと楕円体高を混在させない。

鉛直成分を切り替えた場合は、対象となる縦軸の表示範囲を、切り替え後のデータに合わせて自動調整する。水平軌跡の表示範囲および表示内容には影響しない。

### 3.6 表示範囲を操作する

利用者は、マウスによるパン、マウスホイールによるズーム、軸範囲の数値指定、描画領域長の数値指定、表示縮尺の数値指定、ウィンドウ寸法の変更および表示範囲の自動調整を実行できる。

水平軌跡では、縦軸と横軸に共通の表示縮尺を適用し、等縮尺を維持する。表示縮尺の単位は`m/px`とする。

通常のズームでは表示範囲の中心を固定する。所定のmodifier keyを使用した場合はカーソル位置を固定してズームし、別のmodifier keyを使用した場合は表示縮尺を維持したままウィンドウ寸法を変更する。

時系列では、各位置成分の縦軸表示範囲を独立して操作できる。時刻軸は、表示中の全時系列プロットで共有する。

利用者は、任意の時系列プロットの縦軸表示範囲を、選択した他の時系列プロットへ1回だけ適用できる。

### 3.7 ファイルを非表示または削除する

利用者は、読み込み済みのファイルを非表示にできる。非表示にした場合も、読み込み済みデータは保持する。

利用者は、読み込み済みのファイルをアプリケーションから削除できる。削除はアプリケーション内の読み込み済みデータだけを対象とし、入力ファイル自体を変更しない。

ファイルを非表示または削除しても、現在の表示範囲を自動変更しない。削除後は後続スロットを前方へ詰め、スロット番号を`1`から再割り当てする。

すべてのファイルを削除した場合は、データのない空のプロットを表示する。削除時の確認操作は必須としない。

### 3.8 plotcore fullでplot areaを管理する

`plotcore full`の利用者は、Normal 2D、Normal Time Series、Relative 2DおよびRelative Time Seriesのplot areaを任意個生成できる。

各plot areaは独立したfloating areaとして配置し、個別に表示、非表示、再表示または削除できる。各instanceの軸範囲、描画領域長、表示縮尺、zoom/pan状態および表示成分は、他のinstanceから独立して保持する。

File/Slots areaおよび全plot areaは同じ読み込み済みファイル、スロット順、品質filter、共通時刻範囲、ENU基準およびrelative dataを共有する。

## 4. 機能要件

### 4.1 ファイル読み込み

#### FR-FILE-001 複数ファイルの読み込み

利用者は、1個または複数の対応ファイルを一度に選択して読み込める。プログラムはファイルごとに読み込みの成否を判定し、一部が失敗した場合も成功したファイルの処理を継続する。

#### FR-FILE-002 ファイル形式の判定

ファイル形式は、最初にファイルの拡張子から判定する。拡張子から判定できない場合は、利用者がファイル形式を指定できるものとする。

#### FR-FILE-003 ファイルサイズの確認

ファイルサイズが所定の閾値以上である場合は、読み込み前に警告し、利用者が読み込みの続行または中止を選択できるものとする。閾値は実装時に定める。

#### FR-FILE-004 重複読み込み

同一のファイルパスを複数回読み込むことを許容し、各読み込み結果を独立した読み込み済みファイルとして扱う。

#### FR-FILE-005 部分読み込み

ファイル内の一部の行、recordまたはepochの解析に失敗した場合も、解析に成功した部分を読み込めるものとする。

解析に失敗した部分については、対象ファイル、失敗位置および失敗理由を通知する。有効なsampleを1件も取得できなかった場合は、ファイル全体の読み込み失敗として扱う。

### 4.2 ファイルスロット

#### FR-SLOT-001 スロットへの配置

読み込み済みファイルは、`1`から`n`までの連続した番号を持つスロットへ配置する。実装上の最大ファイル数を設定することは許容し、具体的な上限は性能検証に基づいて定める。

#### FR-SLOT-002 表示名

各スロットの基本表示名にはファイル名を使用する。同名のファイルが複数存在する場合は、スロット番号によって識別できるものとする。

#### FR-SLOT-003 スロットの並べ替え

利用者はスロット順を入れ替えられる。並べ替え後も、スロット番号は`1`から`n`までの連番とする。

#### FR-SLOT-004 スロットの削除

スロットを削除した場合は、後続スロットを前方へ詰め、スロット番号を`1`から再割り当てする。スロット1を削除した場合は、削除前のスロット2を新しいスロット1とする。

#### FR-SLOT-005 表示状態

各スロットは個別に表示または非表示へ切り替えられる。非表示にした場合も読み込み済みデータを保持し、表示状態の変更によって表示範囲を自動変更しない。

### 4.3 plotcore lightの表示モード

#### FR-VIEW-001 タブ構成

表示モードとして、以下の6個のタブを設ける。

1. 通常表示の水平軌跡
2. 通常表示の時系列
3. 通常表示の水平軌跡および時系列
4. 基準相対表示の水平軌跡
5. 基準相対表示の時系列
6. 基準相対表示の水平軌跡および時系列

#### FR-VIEW-002 起動時の表示

アプリケーション起動時は、通常表示の水平軌跡タブを表示する。

#### FR-VIEW-003 両方表示

水平軌跡および時系列を同時表示するタブでは、両者を左右に配置する。中央の境界線をドラッグして左右幅を変更でき、ダブルクリックすると中央へ戻る。

### 4.4 通常表示

#### FR-NORMAL-001 水平軌跡

表示状態となっている複数ファイルの軌跡を、共通の局所East/North座標系上へ同時に表示する。

#### FR-NORMAL-002 時系列

表示状態となっている複数ファイルについて、East、Northおよび鉛直位置成分を時刻に対して表示する。表示する成分を選択でき、表示中の全subplotで共通の時刻軸を使用する。

### 4.5 基準相対表示

#### FR-REF-001 基準ファイル

スロット1を基準ファイル、スロット2以降を比較ファイルとし、基準ファイルに対する相対位置を表示する。スロット順の変更後は、新しいスロット1を基準ファイルとする。

#### FR-REF-002 epochの対応付け

比較ファイルの各sampleについて、そのsampleと同時刻またはそれ以前に存在する基準ファイルのepochのうち、時刻が最も新しいepochを対応付ける。比較sampleより未来の基準epochは使用しない。

同一の基準epochを複数の比較sampleへ対応付けることを許容する。相対表示データの出力時刻には、比較ファイル側のsample時刻を使用する。

#### FR-REF-003 対応しないsample

比較sample以前の基準epochが存在しない場合、または比較sampleと対応する基準epochとの時刻差が利用者設定可能な最大時刻差を超える場合は、その比較sampleを基準相対表示へ出力しない。

最大時刻差の判定方法は、`data-specification.md`で定義する。

#### FR-REF-004 相対水平位置

基準相対表示の水平軌跡では、比較ファイルの各sampleと、それに対応する基準epochとの相対East成分および相対North成分を表示する。

相対East成分を横軸、相対North成分を縦軸とし、相対位置が0である点を座標原点`(0, 0)`とする。各sampleの相対位置を、この原点を基準とする水平面上へプロットする。

複数の比較ファイルが存在する場合は、それぞれの相対水平位置を同時に表示する。

#### FR-REF-005 相対位置時系列

比較ファイルごとに、基準ファイルに対する相対East、相対Northおよび相対鉛直成分を時系列として表示する。

#### FR-REF-006 距離時系列

相対位置の成分別時系列に加えて、比較sampleと対応する基準epochとの距離を時系列として表示する。距離の定義および計算方法は、`data-specification.md`で定義する。

### 4.6 測位解品質による表示制御

#### FR-QUALITY-001 品質による表示区別

測位解品質によってsampleの表示を視覚的に区別する。

#### FR-QUALITY-002 品質フィルタ

利用者は、測位解品質の分類単位でsampleの表示または非表示を切り替えられる。品質フィルタは表示中の全ファイルへ共通して適用し、ファイル単位の表示状態と組み合わせて表示対象を決定する。

品質分類の定義および入力値との対応付けは、`data-specification.md`で定義する。

### 4.7 鉛直位置成分

#### FR-VERTICAL-001 鉛直成分の選択

利用者は、時系列の鉛直位置成分として、局所座標系のUpまたは楕円体高を選択できる。選択は表示中の全ファイルへ共通して適用し、同一の時系列表示内で両者を混在させない。

#### FR-VERTICAL-002 切り替え時の処理

鉛直位置成分を切り替えた場合は、対象となる縦軸の表示範囲を、切り替え後の表示対象データへ合わせて自動調整する。水平軌跡には影響しない。

### 4.8 表示範囲の自動調整

#### FR-FIT-001 対象データ

自動調整には、ファイル単位の表示状態および品質フィルタの両方を適用した後のsampleだけを使用する。

#### FR-FIT-002 実行条件

最初のファイルを読み込んだ場合は表示範囲を自動調整する。追加読み込み、表示状態変更、スロット並べ替えおよび削除では、現在の表示範囲を維持する。

利用者は、表示対象データ全体へ表示範囲を合わせる操作を明示的に実行できる。

#### FR-FIT-003 水平軌跡の自動調整

水平軌跡の自動調整では、描画領域のピクセル寸法を固定する。

表示対象データのEast方向およびNorth方向の最小値から最大値までが、各方向の描画領域長の90%以内に収まる表示縮尺を設定する。

East方向のデータ範囲を`dE`、North方向のデータ範囲を`dN`、横方向の描画領域長を`pE`、縦方向の描画領域長を`pN`、表示縮尺を`r`とすると、次の値とする。

```text
r = max(
    dE / (0.9 × pE),
    dN / (0.9 × pN)
)
```

表示縮尺の単位は`m/px`とし、実際の表示範囲は次の関係で決定する。

```text
表示East範囲  = pE × r
表示North範囲 = pN × r
```

データ範囲の中心と表示範囲の中心を一致させる。

#### FR-FIT-004 水平軌跡の範囲が定まらない場合

表示対象が1点だけの場合、またはEast方向およびNorth方向のデータ範囲がともに0である場合は、横方向および縦方向のうち短い方の描画領域に対応する物理範囲を1 mとする。

```text
r = 1 m / min(pE, pN)
```

対象点を表示範囲の中心とする。

#### FR-FIT-005 時系列の自動調整

時系列の自動調整では、表示対象データの最小値および最大値を、そのまま対応する軸の最小値および最大値として使用し、余白を追加しない。

表示対象sampleが1件だけである場合、または全sampleの値が同一である場合は、その値を中心として各subplotの縦軸表示範囲を1 mとする。

時刻軸の範囲を表示対象sampleから一意に決定できない場合は、対象sampleの時刻を中心として時刻軸表示範囲を1 minとする。

### 4.9 表示領域

#### FR-AREA-001 利用可能領域

単一プロットではメインウィンドウの利用可能領域全体を使用する。同時表示では、各パネルへ割り当てられた利用可能領域全体を使用し、未使用の空白領域を設けない。

#### FR-AREA-002 描画領域長

描画領域長は、軸ラベル、目盛り、入力欄および操作ボタン等を除いたデータ描画領域のピクセル長とする。

#### FR-AREA-003 寸法制約

描画領域には最小幅、最小高さ、最大幅および最大高さの制約を設ける。具体値および導出方法は実装時に定め、水平軌跡と時系列の両方へ適用する。

#### FR-AREA-004 パネル表示

プロットをパネル内へ表示する場合は、描画領域長を数値で直接指定する機能を提供しない。ウィンドウ寸法またはパネル境界の変更によって描画領域長が変化することは許容する。

### 4.10 共通の最小表示範囲

#### FR-RANGE-001 最小表示範囲

表示範囲は、数値指定、マウス操作その他の変更によって、次の最小範囲を下回らないものとする。

- 水平軌跡では、East軸とNorth軸のうち表示範囲が短い方を1 mm以上とする。
- 時系列では、各subplotの縦軸表示範囲を1 mm以上とする。
- 時刻軸の表示範囲を1 ms以上とする。

水平軌跡では等縮尺を維持するため、短い方の軸へ最小範囲を適用した結果に応じて、他方の軸範囲も決定する。

最小範囲を下回る値が要求された場合は、対応する最小値に制限する。

### 4.11 水平軌跡の表示範囲操作

#### FR-HRANGE-001 表示縮尺

水平軌跡ではEast軸とNorth軸に共通の表示縮尺を適用し、等縮尺を維持する。

East軸の表示範囲を`ΔmE`、North軸の表示範囲を`ΔmN`、横方向の描画領域長を`pE`、縦方向の描画領域長を`pN`、表示縮尺を`r`とすると、次の関係を維持する。

```text
r = ΔmE / pE = ΔmN / pN
```

表示縮尺の単位は`m/px`とする。

#### FR-HRANGE-002 数値指定

水平軌跡では、各軸の最小値および最大値、各方向の描画領域長ならびに表示縮尺を数値で指定できる。パネル表示では、描画領域長の数値指定を提供しない。

#### FR-HRANGE-003 表示縮尺優先モード

表示縮尺優先モードでは表示縮尺を固定する。

軸範囲を指定した場合は`p = Δm / r`により対象方向の描画領域長を変更する。描画領域長を指定した場合は`Δm = p × r`により対象軸の表示範囲を変更する。

表示縮尺を指定した場合は、全軸共通の固定対象設定に従い、描画領域長または軸範囲を固定する。固定対象設定の初期値は描画領域長固定とする。

ウィンドウ寸法を変更した場合は、表示縮尺を維持し、変更後の描画領域長に応じて各軸の表示範囲を変更する。

#### FR-HRANGE-004 寸法制約到達時の処理

表示縮尺優先モードで必要な描画領域長が寸法制約を超える場合は、描画領域長を制約内へ収める。この場合は表示縮尺を維持し、制約適用後の描画領域長に応じて軸範囲を変更する。

利用者が指定した軸範囲を維持できない場合は、そのことを通知する。

#### FR-HRANGE-005 軸優先モード

軸優先モードで軸範囲を指定した場合は、操作対象軸の描画領域長を固定し、`r = Δm / p`によって表示縮尺を変更する。

描画領域長を指定した場合は、操作対象軸の表示範囲を固定し、同じ関係によって表示縮尺を変更する。

一方の軸の操作によって表示縮尺が変化した場合は、他方の軸の描画領域長および表示範囲の中心を固定し、`Δmother = pother × r`によって他方の軸範囲を変更する。他方の軸の最小値および最大値は中心に対して対称に変更する。

#### FR-HRANGE-006 パン

水平軌跡の描画領域上でマウス左ボタンをドラッグした場合は、East軸およびNorth軸を同時に平行移動する。

左右の矢印キーではEast軸方向だけを移動し、上下の矢印キーではNorth軸方向だけを移動する。1回のキー操作による移動量は実装時に定める。

#### FR-HRANGE-007 ホイールズーム

通常のマウスホイール操作では、表示範囲の中心を固定して表示縮尺を変更する。

所定のmodifier keyを押しながら操作した場合は、カーソル位置に対応する座標を固定して表示縮尺を変更する。

別のmodifier keyを押しながら操作した場合は、表示縮尺を維持したままウィンドウ寸法を縦横同時に変更する。この操作には描画領域の寸法制約を適用する。

modifier keyの具体的な割り当ておよびホイール1段当たりの変化量は実装時に定める。

#### FR-HRANGE-008 軸上の操作

各軸には最小値、最大値および描画領域長を表示する。各値にカーソルを合わせてマウスホイールを操作した場合は、対象値を数値指定した場合と同じ規則を適用する。

### 4.12 時系列の表示範囲操作

#### FR-TRANGE-001 表示対象

時系列ではEast、Northおよび鉛直位置成分から表示する成分を選択できる。表示対象が複数存在する場合は、利用可能な縦方向の描画領域を表示対象数で等分する。

表示対象数を変更した場合は、時系列表示領域全体の高さを維持し、各subplotの高さを再計算する。

#### FR-TRANGE-002 独立した縦軸

各時系列subplotは独立した縦軸の最小値および最大値を保持する。時刻軸は、表示中の全subplotで共有する。

#### FR-TRANGE-003 数値指定

時系列では、各縦軸の最小値および最大値、共通時刻軸の最小値および最大値、時系列表示領域全体の縦方向描画領域長ならびに横方向描画領域長を数値で指定できる。

パネル表示では描画領域長の数値指定を提供しない。

縦軸または時刻軸の範囲を指定した場合は対応する描画領域長を固定する。描画領域長を指定した場合は、対応する縦軸範囲または時刻軸範囲を固定する。

ウィンドウ寸法またはパネル境界を変更した場合は、描画領域長を指定した場合と同じ規則を適用する。

#### FR-TRANGE-004 縦軸範囲の適用

各時系列subplotには、そのsubplotの縦軸最小値および最大値を、選択した他の表示中subplotへ適用する操作を設ける。

適用は操作時に1回だけ実行し、その後のパン、ズームまたは数値指定を継続的に連動させない。適用先として選択されていないsubplotの縦軸範囲は変更しない。

#### FR-TRANGE-005 縦軸のホイール操作

各時系列subplotの描画領域上でマウスホイールを操作した場合は、カーソルが存在するsubplotの縦軸表示範囲だけを変更する。

通常操作では縦軸範囲の中点を固定し、所定のmodifier keyを押した場合はカーソル位置に対応する値を固定する。

#### FR-TRANGE-006 時刻軸のホイール操作

最下部の時刻軸上でマウスホイールを操作した場合は、全subplotで共有する時刻軸表示範囲を変更する。

通常操作では時刻範囲の中点を固定し、所定のmodifier keyを押した場合はカーソル位置に対応する時刻を固定する。

#### FR-TRANGE-007 寸法制約

時系列の描画領域にも最小寸法および最大寸法の制約を適用する。具体的な制約値は実装時に定める。

### 4.13 エラーおよび警告

#### FR-ERROR-001 ファイル読み込み失敗

ファイル読み込みに失敗した場合は、対象ファイルおよび失敗理由を通知する。

#### FR-ERROR-002 部分読み込み警告

ファイルの一部だけを読み込んだ場合は、対象ファイル、失敗位置および失敗理由を通知する。

#### FR-ERROR-003 ファイルサイズ警告

ファイルサイズが所定の閾値以上の場合は、読み込みの続行または中止を利用者へ確認する。

#### FR-ERROR-004 表示範囲変更警告

表示縮尺優先モードにおいて、寸法制約のため利用者が指定した軸範囲を維持できない場合は、そのことを通知する。

### 4.14 共通処理時刻範囲

#### FR-TIME-001 共通時刻範囲

利用者は、読み込み済みの全ファイルへ共通して適用する処理対象時刻範囲を指定できる。時刻範囲はstartおよびendを含む閉区間とする。

初期値は、読み込み済み全ファイルの時刻範囲のunionとする。

#### FR-TIME-002 範囲候補

共通時刻範囲の指定dialogには、全ファイルのunionおよびintersectionを入力欄へ反映するbuttonを設ける。

button操作は入力欄を更新するだけとし、利用者が`OK`を実行するまで時刻範囲を適用しない。intersectionが存在しない場合は現在の入力値を維持し、そのことを通知する。

#### FR-TIME-003 適用対象

通常表示、基準epochとの対応付け、基準相対表示、品質別統計その他の後段処理は、共通時刻範囲内のsampleだけを対象とする。

### 4.15 ENU基準位置

#### FR-ENU-001 基準位置の選択

共通ENU座標系の基準位置は、以下から選択できるものとする。

- 共通時刻範囲内にあるスロット1の先頭sample
- 共通時刻範囲内にあるスロット1の末尾sample
- 共通時刻範囲内にあるスロット1のECEF座標平均
- 利用者指定位置

品質`0`のsampleも、先頭、末尾および平均の算出対象へ含める。

#### FR-ENU-002 利用者指定位置

利用者指定位置は、入力欄上の選択によりLLHまたはECEFで指定できるものとする。

#### FR-ENU-003 再計算

スロット1、共通時刻範囲、基準位置方式または利用者指定位置が変更された場合は、ENU基準位置および読み込み済みsampleのENU座標を再計算する。

スロット1に共通時刻範囲内のsampleが存在せず基準位置を決定できない場合は、そのことを通知する。

### 4.16 ファイルrate

#### FR-RATE-001 Hzの推定

各読み込み済みファイルについて、一定rateを仮定してHzを推定する。推定方法は`data-specification.md`で定義する。

#### FR-RATE-002 手動指定

利用者はファイルごとにHzを手動指定できる。手動指定値が存在する場合は推定値より優先し、手動指定を解除して推定値へ戻す操作を提供する。

### 4.17 ステータス統計

#### FR-STAT-001 Recorded mode

Recorded modeでは、共通時刻範囲内にファイルへ記録されているsample数を品質別割合の母集団とする。

#### FR-STAT-002 Expected mode

Expected modeでは、共通時刻範囲のstart、endおよびファイルの有効Hzから算出した期待epoch数を品質別割合の母集団とする。

期待epoch数の算出では、ファイル自身の時刻範囲による切り詰めを行わない。算出方法は`data-specification.md`で定義する。

#### FR-STAT-003 モード切り替え

利用者はRecorded modeおよびExpected modeを循環して切り替えられる。

### 4.18 NMEA読み込み時の確認

#### FR-NMEA-001 ジオイド高欠損

GGAのジオイド高が欠損している場合はmodal dialogを表示し、GGAの標高を楕円体高として読み込むか、読み込みを中止するかを利用者が選択できるものとする。

#### FR-NMEA-002 日付指定

有効なRMCまたはZDAが存在せずGGAの日付を確定できない場合は、読み込み完了前に日付指定dialogを表示する。

dialogにはファイル時刻から取得した日付を入力欄へ反映するbuttonを設け、利用者が`OK`を実行した時点で日付を確定する。

#### FR-NMEA-003 日時validation

2件目以降のRMCまたはZDAによる日時validationが設定された許容差を超えて失敗した場合は、popup警告を表示する。

#### FR-NMEA-004 非対応talker

`GP`および`GN`以外のtalker IDを持つGGA、RMCまたはZDAは読み飛ばし、警告する。

### 4.19 plotcore fullのplot area

#### FR-FULL-001 File/Slots area

`plotcore full`は、読み込み済みファイルおよびスロットを操作するFile/Slots areaを持つ。File/Slots areaは表示および非表示を切り替えられるものとする。

#### FR-FULL-002 plot areaの種類

`plotcore full`は、以下の4種類のplot areaを生成できるものとする。

- Normal 2D
- Normal Time Series
- Relative 2D
- Relative Time Series

`plotcore full`では、水平軌跡と時系列を1個のareaへ組み合わせるBoth表示を設けない。

#### FR-FULL-003 任意個のinstance

各種類のplot areaを任意個生成できるものとする。実装上の最大instance数を設定することは許容し、具体的な上限は性能検証に基づいて定める。

#### FR-FULL-004 floating area

各plot instanceはapplication内の独立したfloating areaとして表示し、利用者が移動および寸法変更できるものとする。

#### FR-FULL-005 lifecycle

各plot instanceは個別に表示、非表示、再表示および削除できるものとする。非表示状態ではinstanceおよびそのview stateを保持する。

#### FR-FULL-006 instance固有状態

各plot instanceは、軸範囲、描画領域長、表示縮尺、zoom/pan状態、auto-fit状態、描画形式および表示成分を独立して保持する。

#### FR-FULL-007 共通状態

読み込み済みファイル、スロット順、ファイル表示状態、品質filter、共通時刻範囲、ENU基準、基準epoch対応tolerance、正規化データおよびrelative dataは、すべてのplot instanceで共有する。

plot instanceの追加によって、同一の正規化処理、ENU変換または基準epoch対応付けをinstanceごとに重複実行しない。

## 5. 表示要件

本節では、機能要件で定義したデータおよび操作を画面上で識別し、操作するための表示要件を定義する。

入力データの解釈、時刻の正規化、重複epochの処理、基準epochとの対応付けおよび測位解品質の分類規則は、`data-specification.md`で定義する。

### 5.1 plotcore lightの画面構成およびタブ

#### DR-VIEW-001 タブバー

表示モードのタブバーは2行で構成する。

各行には、表示種別を選択する以下の3個のタブを横方向に配置する。

- Trajectory
- Time Series
- Both

一方の行を通常表示、他方の行を基準相対表示とし、`Normal`および`Reference`のモード名を常時表示する。

起動時は、`Normal`の`Trajectory`タブを選択した状態とする。

タブの最終的な表示名は英語とし、具体的な表記は実装時に定める。

#### DR-VIEW-002 両方表示

`Both`タブでは、水平軌跡を左側、時系列を右側に配置する。

中央の境界線をドラッグすることにより左右の表示幅を変更できるものとする。

中央の境界線をダブルクリックした場合は、境界線を表示領域の中央へ戻す。

軸、目盛り、入力欄、操作ボタンその他のUIに必要な領域を除き、未使用の空白領域を設けない。

### 5.2 plotcore lightのファイルスロット表示と操作

#### DR-SLOT-001 左サイドバー

画面左端に、折り畳み可能なファイル管理用サイドバーを設ける。

サイドバーは、ハンバーガーボタンをクリックした場合に展開する。

展開中にハンバーガーボタンを再度クリックした場合、またはサイドバー以外の領域をクリックした場合は、サイドバーを折り畳む。

#### DR-SLOT-002 スロットアイコン

読み込み済みファイルに対応するスロット`1`から`n`までのアイコンは、サイドバーの展開状態にかかわらず常時表示する。

スロットアイコンをクリックした場合は、対応するファイルの表示・非表示を切り替える。

スロットアイコンをドラッグした場合は、スロット順を並べ替える。

スロットアイコンのcontext menuから、対応するファイルを削除できるものとする。

展開したファイル一覧には、各ファイルの推定Hzまたは手動指定Hzを表示する。context menuからHzを手動指定でき、手動指定を解除して推定値へ戻すことができるものとする。

スロットアイコンのtooltipには、暫定的にファイル名だけを表示する。

スロット1は、基準相対表示における基準ファイルであることを識別できる表示とする。

#### DR-SLOT-003 選択状態

ファイルスロットには、継続的な「選択中」状態を設けない。

クリック、ドラッグおよびcontext menuによる操作は、その操作対象となったスロットだけに適用する。

### 5.3 軌跡および時系列の描画

#### DR-PLOT-001 描画形式

軌跡および時系列の描画形式として、以下を設定可能とする。

- 線のみ
- 点のみ
- 線および点

点の大きさは、位置または時刻の表示縮尺に依存しないピクセル単位で指定する。

#### DR-PLOT-002 sample間の接続

sample間を線で接続する場合は、灰色の線を使用する。

測位解品質が変化する位置では接続線を分割しない。

品質フィルタによって中間sampleが非表示となった場合に、その前後の表示sampleを線で接続するかどうかを設定可能とする。

#### DR-PLOT-003 時刻異常および基準epoch未対応sample

時刻が逆行するrecordは読み込み時に除去し、非modal警告を表示する。

同一時刻のrecordが複数存在する場合は、入力上で後に現れたrecordだけを残し、非modal警告を表示する。

基準相対表示では、比較sampleと同時刻またはそれ以前に存在する最新の基準epochを使用する。該当する基準epochが存在しない場合、またはその基準epochとの時刻差が設定されたtoleranceを超える場合は、その比較sampleを表示しない。

toleranceは利用者が設定可能とする。

時刻異常、重複epochおよび基準epoch対応付けの詳細規則は、`data-specification.md`で定義する。

### 5.4 ファイルおよび測位解品質の識別

#### DR-IDENT-001 測位解品質の色

sampleの色は、測位解品質を表す。

既定色はRTKPLOTのFile 1に対する既定配色へ準拠する。

品質分類、入力値との対応付けおよび具体的な色は、RTKPLOTの実装を確認したうえで`data-specification.md`に定義する。

#### DR-IDENT-002 スロットのマーカー形状

ファイルスロットは、以下のマーカー形状によって区別する。

- スロット1：円
- スロット2：X形
- スロット3以降：スロット番号と同じ頂点数を持つ正多角形

ファイルスロットの識別には色を使用しない。

### 5.5 描画順序

#### DR-ORDER-001 スロット間の描画順序

既定では、スロット番号が大きいファイルほど手前に描画する。

設定により、スロット番号が小さいファイルほど手前に描画する順序へ変更できるものとする。

#### DR-ORDER-002 同一スロット内の描画順序

同一スロット内では、既定で良品質のsampleほど手前に描画する。

設定により、低品質のsampleほど手前に描画する順序へ変更できるものとする。

品質間の順序は、`data-specification.md`で定義する品質分類順に従う。

選択状態に基づく描画順序の変更は行わない。

### 5.6 軸、時刻、目盛りおよびグリッド

#### DR-AXIS-001 軸表記

軸ラベルは英語表記とし、文字列、位置、数値表示および単位表記はRTKPLOTへ準拠する。

具体的な表記は、RTKPLOTの実装を確認したうえで本節へ追記する。

#### DR-AXIS-002 時刻表記

時系列の時刻軸には絶対GPSTを表示する。

GPSTの具体的な表示書式はRTKPLOTへ準拠し、RTKPLOTの実装を確認したうえで本節へ追記する。

#### DR-AXIS-003 tickおよびグリッド

tickの生成規則、主目盛り、補助目盛りおよびグリッドの表示方法はRTKPLOTへ準拠する。

ゼロ線とその他のグリッドの線種を含む具体的な描画規則は、RTKPLOTの実装を確認したうえで本節へ追記する。

### 5.7 数値入力

#### DR-INPUT-001 表示精度

数値入力欄は、非編集時に有効数字3桁で表示する。

編集開始時は、対象値を高精度で表示する。

#### DR-INPUT-002 値の確定および取消し

Enterキーによって入力値を確定する。

無効な入力値は赤色で表示する。

無効な入力値を確定せずに別の領域をクリックした場合は、入力欄を直前の有効値へ戻す。

#### DR-INPUT-003 位置単位

位置を表す数値入力欄では、単位表示をクリックすることにより、以下の単位を循環して切り替える。

```text
km → m → mm → km
```

単位変更は数値入力欄の表示値および入力値だけに適用し、内部値および軸ラベルの単位表記は変更しない。

#### DR-INPUT-004 表示縮尺の単位

水平軌跡の表示縮尺入力欄では、以下の単位を切り替え可能とする。

- `km/px`
- `m/px`
- `mm/px`

単位変更は表示値および入力値だけに適用し、内部の表示縮尺を変更しない。

### 5.8 データ概要

#### DR-SUMMARY-001 表示内容

画面最下部に、読み込み済みデータの概要を表示する。

1スロットにつき1行を使用し、各行には少なくとも以下を表示する。

- データの開始時刻
- データの終了時刻
- 品質分類ごとのepoch数
- 品質分類ごとの割合

#### DR-SUMMARY-002 表示行数

5行までは、各スロットの概要を改行して表示する。

6行以上の場合は、概要表示領域をスクロール可能とする。

#### DR-SUMMARY-003 統計モード

データ概要の右側に、Recorded modeおよびExpected modeを循環して切り替えるbuttonを設ける。

現在の統計モードをbutton上または隣接する表示によって識別できるものとする。Expected modeを算出できないファイルについては、その状態を行内に表示する。

#### DR-SUMMARY-004 共通時刻範囲

共通時刻範囲を指定するdialogには、startおよびendの入力欄ならびに`Union`、`Intersection`および`OK`の操作を設ける。

`Union`または`Intersection`は対応する候補値を入力欄へ反映し、`OK`によって適用する。

### 5.9 通知および警告

#### DR-NOTIFY-001 通知履歴

画面右上にinfo buttonを設ける。

info buttonをクリックした場合は、過去の通知、警告および読み込み結果を表示する通知履歴ウィンドウを開く。

通知履歴はClear操作によって消去できるものとする。

#### DR-NOTIFY-002 caution indicator

非modal警告が通知履歴に存在する場合は、info buttonの左側にcaution indicatorを表示する。

caution indicatorは、通知履歴のClear操作によって消去する。

通知履歴ウィンドウを開くだけでは、caution indicatorを消去しない。

#### DR-NOTIFY-003 modal警告

ファイルサイズ警告等、処理の続行または中止について利用者の判断を必要とする警告はmodal dialogとして表示する。

部分読み込み、時刻逆行および時刻重複等、処理を継続できる警告は非modal通知として通知履歴へ追加する。

### 5.10 plotcore fullのwindow表示

#### DR-FULL-001 File/Slots area

File/Slots areaは他のplot areaから独立して表示し、利用者が表示または非表示を切り替えられるものとする。

#### DR-FULL-002 plot instanceの識別

同じ種類のplot areaを複数表示した場合も、各instanceをwindow titleまたはinstance番号によって識別できるものとする。

#### DR-FULL-003 独立した描画領域

各plot instanceは固有の描画領域を持つ。描画領域長の数値指定、window resize、軸範囲および表示縮尺の関係には、共通のプロット要件を適用する。

#### DR-FULL-004 非表示instance

非表示のplot instanceは描画処理の対象外とする。再表示した場合は、非表示前のview stateを復元する。
